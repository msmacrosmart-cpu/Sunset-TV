SunsetTV - como gerar o APK

Opcao A (Android Studio): abra a pasta SunsetTV > aguarde o Sync > Build > Build APK(s).
  O arquivo sai em app/build/outputs/apk/debug/app-debug.apk

Opcao B (sem instalar nada): suba esta pasta para um repositorio no GitHub.
  Aba Actions > "Build APK" > Run workflow > baixe o artefato "SunsetTV-debug-apk".

Instalar na TV/TV Box: copie o .apk por pendrive ou use "adb install app-debug.apk".
